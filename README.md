E-Commerce Web Application
This is a full-fledged e-commerce platform built using React.js for the frontend, featuring a protected authentication system and dynamic product listing. The application provides a seamless shopping experience by displaying exclusive deals for prime users and a categorized list of all available products.

Key Features
1. User Authentication & Protected Routes
Users must log in using their credentials, which are validated through JWT-based authentication.
Protected routes ensure only authenticated users can access the core functionalities like browsing products and managing their cart.
2. Prime Deals Section
Displays exclusive deals for users with a premium subscription.
Data is fetched from a backend API, and the UI dynamically updates based on the API response.
Handles different states like loading, success, and failure.
3. All Products Section
A complete list of products available for purchase.
Products can be sorted dynamically using a dropdown menu to enhance the user experience.
4. Product Card Component
Each product is displayed in a structured format, showcasing details like:
Title
Brand
Price
Rating
Thumbnail Image
5. Cart Management
Users can add products to their cart and view them separately.
6. Error Handling & Not Found Page
A custom 404 page ensures users don’t land on broken links.
Technology Stack
Frontend: React.js, CSS
State Management: React Component State
Authentication: JWT (Stored in Cookies)
API Handling: Fetch API
Routing: React Router
This project follows a modular approach, making it scalable and easy to maintain. The implementation of authentication, dynamic product sorting, and protected routes ensures a secure and smooth shopping experience for users.
